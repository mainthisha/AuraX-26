# ⚡ AuraX'26

### Innovation Ignites the Future.

A modern full-stack digital platform for technical college festivals, designed to make event discovery, registration, scheduling, preparation, and participant engagement simple and interactive.

---

## 🌟 What We Do

AuraX'26 brings the complete festival experience into one platform.

### 🎯 Event Discovery
- Explore and search festival events
- Filter events by category
- View event details, timings, venues, prizes, and requirements
- Get personalized event recommendations

### 📅 Smart Event Management
- Register and unregister for events
- Bookmark events
- Detect schedule clashes
- View an interactive festival timeline
- Manage registered events from a personalized dashboard

### 📚 Preparation Hub
Access curated resources to prepare for technical events, including:

- Competitive Programming
- AI & Machine Learning
- UI/UX Design
- Robotics & IoT
- Full-Stack Development

### 🧑‍🏫 Mentor Support
- Explore mentors by technical domain
- Check mentor availability
- Select mentors based on expertise
- Submit help requests

### 👥 Participant Networking
- Explore other participants
- View skills, interests, and participating events
- Create and customize participant profiles

### 🔎 Smart FAQ
Quickly find answers related to:

- Registration
- Events
- Schedule
- Venues
- Certificates
- Food
- General festival information

### 🎟️ Digital Festival Pass
Generate a personalized digital pass containing:

- Participant details
- Pass ID
- Registered events
- QR-based identification

### ⏱️ Live Festival Countdown
An interactive countdown keeps participants connected to the upcoming festival with real-time days, hours, minutes, and seconds.

## ⚙️ Run Locally

### Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Then open the local URL shown in the terminal.
